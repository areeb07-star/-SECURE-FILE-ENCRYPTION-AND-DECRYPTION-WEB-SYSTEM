# 🔐 Secure File Encryption and Decryption Web System

## 📖 Overview

The **Secure File Encryption and Decryption Web System** is a web-based application developed as an academic group project. It provides a secure and user-friendly platform for encrypting and decrypting files using cryptographic techniques. The system helps protect sensitive data by converting files into an encrypted format and allowing only authorized users to decrypt them.

The project demonstrates the practical implementation of cryptography in web applications while focusing on data security, ease of use, and efficient file management.

---

## ✨ Features

- 🔒 Secure file encryption
- 🔓 Secure file decryption
- 📂 Upload and download files
- 🛡️ Protection of sensitive data using encryption
- 💻 Simple and user-friendly interface
- ⚡ Fast and efficient file processing

## 🚀 Installation & Usage

1. Clone the repository:

```bash
git clone https://github.com/areeb07-star/-SECURE-FILE-ENCRYPTION-AND-DECRYPTION-WEB-SYSTEM.git
```

2. Navigate to the project folder:

```bash
cd -SECURE-FILE-ENCRYPTION-AND-DECRYPTION-WEB-SYSTEM
```

3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

5. Open your browser and visit:

```
http://127.0.0.1:5000
```
